1. Overview

The Training Dashboard is a single HTML file that reads the master Excel workbook and produces interactive charts and tables. It runs entirely in your browser — no server, no installation. All calculations happen live from the data in the file you drop in.

What you need A modern browser (Chrome, Edge, or Firefox) and the current copy of TechnicalTrainingSchedule_2026.xlsx. No internet connection is required after the page first loads.

Room Utilisation (2026)Booked and available days per room per month — drives all room KPIs, charts and tables

2. Loading the data

  1. Open report-viewer-v2.html in your browser.
  2. You will see a drop zone. Either drag and drop the Excel file onto it, or click "Browse" to select it from your computer.
  3. The dashboard builds automatically — this typically takes 1–2 seconds.
  4. To load a different file, click "Load New File" (top-right of the page) to reset and start again.
Tip — keeping the file fresh The dashboard always reads from the file you drop in. To see the latest figures, simply save the Excel workbook and reload the HTML page, then drop the file again.

3. Dashboard Tab

The Dashboard tab shows trainer performance for the year. A YTD / Full Year toggle at the top of the page switches every chart, table, and KPI between:

  • Jan – End of Month (YTD) — only the months that have passed so far this year (up to the last complete month)
  • Full Year — all 12 months of planned data

KPIHow it is calculated

3.2 Trainer Overview cards

One card per trainer shows their total training days in the selected period, a progress bar against their cumulative target, and a colour-coded status:

On or above target Within 10 % below target More than 10 % below target

The cumulative target is 12.5 days × number of months in the period.

3.3 Monthly Training Days chart (bar)

A grouped bar chart with one bar per trainer per month. A dashed horizontal line marks the monthly target of 12.5 days. Hovering over a bar shows exact values.

3.4 Cumulative Training Days chart (line)

Running total of training days for each trainer across the year. A diagonal line shows the target ramp (12.5 days per month). Trainers above the line are ahead of target; below the line means behind.

3.5 Monthly Training Days table

A row per month, a column per trainer. Each cell shows the number of training days that month. A coloured dot in each cell indicates performance against the 12.5-day monthly target:

≥ 12.5 days 8–12.4 days < 8 days No data / not applicable

The Cumulative column on the right shows the running total to date and is highlighted in navy to distinguish it from individual months.

3.6 Activities chart and table

A stacked bar chart shows, for each trainer, how their working days in the period are split between Training Courses, Other Activities, and Unassigned days. The data comes directly from the Schedule 2026 sheet — each non-weekend, non-bank-holiday day is categorised by its cell value.

CategoryWhat counts as this
Training CoursesCells whose value starts with a letter followed by a digit (e.g. A1, B2, C301) — standard MB course codes
Other ActivitiesAny other text that is not blank, "Weekend", or "Bank Holiday" (e.g. admin, events, prep days)
UnassignedEmpty or explicitly "Unassigned" cells on working days

A summary table below the chart lists exact day counts per trainer for each category and shows the percentage of total days each represents.

4. Rooms Tab

The Rooms tab covers utilisation of the six training rooms: TW1+Studio, TW2, TW3, TW10, TW11, TR1. A Jan – End of Month / Full Year toggle at the top of the tab updates the KPI boxes, charts, and detail tables simultaneously. The heatmap always shows the full year.

4.2 Weekly Room Booking Heatmap

A grid covering all 52 weeks of the year. Rows are rooms; columns are weeks. Each cell shows how many days that room was booked in that week. Deeper colour = more bookings. The TOTAL row at the bottom (navy background) shows the combined bookings across all rooms for each week.

The Cumulative column on the right gives each room's running total for the full year.

4.3 Room Utilisation — Booked vs Available chart (bar)

A horizontal stacked bar chart with one bar per room. The bar is split into Booked days (blue) and Unallocated days (grey). A dashed vertical line marks the 66% utilisation target.

4.4 Monthly Utilisation % by Room chart (line)

A multi-line chart showing each room's utilisation percentage month by month. A dashed line marks the 66% target. Useful for spotting seasonal patterns or rooms that consistently under- or over-perform.

4.5 Room Detail table

One row per room. Columns show: Booked days, Available days, Utilisation %, and the variance above or below the 66% target. Rows are ordered by the standard room sequence (TW1+Studio → TW2 → TW3 → TW10 → TW11 → TR1).

4.6 Monthly Booking Detail table

One row per month. Columns show total booked days across all rooms, total available days, and the combined utilisation % for that month. Useful for seeing which months are busiest and which have the most slack.

7. Security & Data Privacy

Your data never leaves your device The dashboard is a self-contained HTML file. It has no server, no back-end, and makes no network requests of any kind after the initial page load. Everything — file reading, calculations, charts — runs entirely inside your browser on your own machine.

How the file is read

When you drop the Excel workbook onto the dashboard, the browser reads it using a JavaScript library (SheetJS) that processes the file locally in memory. The spreadsheet data is never uploaded, transmitted, or stored anywhere outside your browser tab. Closing the tab or refreshing the page discards all loaded data immediately.

No internet connection required

After the HTML file has been opened once (which loads Chart.js and SheetJS from a CDN), no further internet access is needed. If you want to use it in a fully offline environment, the libraries can be embedded directly into the file — speak to your dashboard administrator.

No cookies, no tracking, no login

The dashboard does not set any cookies, does not use local storage, and has no analytics or tracking code. It does not require a login and holds no user credentials.

Sharing the report

Because the HTML file itself contains no data (data only exists in memory while a file is loaded), you can share report-viewer-v2.html freely — it is just a viewer. If you want to share results, use your browser's Print → Save as PDF function to create a snapshot. The PDF will contain whatever is currently displayed on screen and can then be distributed through your normal secure channels (email, SharePoint, etc.).

Sensitive data guidance

The source Excel workbook (TechnicalTrainingSchedule_2026.xlsx) contains employee scheduling information. Handle and store this file in line with your organisation's data handling policy. Do not leave it in publicly accessible locations (e.g. a shared desktop or an unprotected shared drive). The dashboard HTML file itself is safe to share.

8. Common Questions

Why are some months blank in charts?

Future months appear with zero or no values because the Schedule sheet has not been filled in yet. This is expected — data will populate as the year progresses and the file is updated.

What does "End of Month" mean in the YTD label?

The dashboard looks at today's date and counts all complete months up to and including the most recently finished month. For example, if today is 12 May 2026, the YTD period covers January through April 2026 (the last complete month).

Why do the trainer cards show a different number from the monthly table total?

If the YTD / Full Year toggle is on different settings between sections — it isn't, the toggle controls all sections together. If there is still a discrepancy, check that the Dashboard (2026) sheet and the Schedule 2026 sheet are both up to date in the Excel file.

How do I update the data?

Update the Excel workbook as normal, save it, then click "Load New File" in the dashboard and drop the updated file in again. The entire dashboard rebuilds from scratch.

The page looks fine but no charts appear — what's wrong?

Make sure you are opening the HTML file in Chrome, Edge, or Firefox. Internet Explorer and older browsers are not supported. Also ensure the Excel file is the correct one (TechnicalTrainingSchedule_2026.xlsx) — dropping an older version will produce incorrect figures.

Can I print this dashboard?

Yes — use your browser's File → Print (or Ctrl + P / ⌘ P) and select "Save as PDF". For the best result choose landscape orientation and set margins to "Minimum" or "None".
